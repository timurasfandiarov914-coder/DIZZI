# DIZZI

Мобильное музыкальное discovery-приложение для браузера.

## Возможности

- Адаптивный интерфейс для мобильных устройств.
- Поиск доступных публичных треков в каталоге Audius.
- Полноформатное потоковое воспроизведение доступных записей Audius.
- Поисковые ссылки на SoundCloud, YouTube Music, Spotify, Deezer и Apple Music.
- Встраиваемые официальные плееры для поддерживаемых ссылок SoundCloud, YouTube, Spotify и Deezer.
- Избранное хранится локально в браузере.
- Бесплатная публикация через GitHub Pages.

## Сторонние музыкальные сервисы

Кнопки сервисов открывают их собственные страницы поиска. Для встроенного воспроизведения нужно вставить публичную ссылку на конкретный трек/альбом/плейлист в поле DIZZI. Встроенный плеер загружает контент с официального домена сервиса; он не скачивает и не хранит аудио.

Доступность полного воспроизведения зависит от прав на запись, региона, настроек встраивания и наличия/типа аккаунта. Не все коммерческие песни могут быть доступны бесплатно. SoundCloud API для автоматического каталожного поиска требует приложения и API credentials, поэтому DIZZI использует официальные embeds и ссылки для поиска, не обходя аутентификацию провайдера.
