# DIZZI

**DIZZI** — адаптивное музыкальное веб-приложение: единый поиск, встроенное воспроизведение, очередь, избранное, история и личные плейлисты.

## Возможности

- Мобильный и настольный интерфейс в стиле современных музыкальных сервисов.
- Общий поиск по публичному каталогу YouTube через несколько публичных экземпляров Invidious и по открытому каталогу Audius.
- Официальный YouTube IFrame Player API для воспроизведения видео с музыкой непосредственно в приложении.
- Полноформатное потоковое воспроизведение записей Audius, доступных для стриминга.
- Единый мини-плеер с play/pause, предыдущим/следующим треком, временем, перемоткой, громкостью, перемешиванием и режимами повтора.
- Очередь воспроизведения с добавлением и удалением треков.
- Избранное, история прослушивания, локальные плейлисты и сохранение очереди через localStorage.
- Горячие клавиши: пробел — пауза/воспроизведение, ←/→ — предыдущий/следующий трек, / — поиск.
- PWA-манифест и service worker: сайт можно добавить на главный экран Android; оболочка интерфейса кэшируется для повторного открытия. Каталоги и музыка требуют интернета.
- Автоматическая проверка JavaScript, DOM-ссылок и PWA-файлов перед публикацией через GitHub Actions.
- Автоматическая публикация через GitHub Pages без сборки и платного хостинга.

## Источники и ограничения

**YouTube:** поиск выполняется через публичные экземпляры Invidious; найденное видео воспроизводится во встроенном официальном YouTube-плеере. Публичные серверы могут быть нестабильны, не все ролики разрешают встраивание, а доступность треков зависит от региона и владельца. В приложение не загружается и не извлекается аудиодорожка.

**Audius:** используется публичный read-only API для поиска и потокового воспроизведения доступных записей. Каталог не включает все коммерческие релизы.

## Архитектура

DIZZI опубликован на GitHub Pages как статическая HTML/CSS/JavaScript-страница. Поэтому серверная часть OpenTune/ytmusicapi не запускается прямо на Pages; текущая версия использует публичные API-источники из браузера. В качестве архитектурного примера изучен [OpenTune](https://github.com/harshitethic/OpenTune) — открытый музыкальный веб-клиент с поиском, очередью и официальным встроенным YouTube-плеером.
