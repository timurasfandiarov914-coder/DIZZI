# DIZZI

Мобильный веб-прототип музыкального discovery-приложения.

## Сейчас работает
- Адаптивный тёмный интерфейс для Android и мобильного браузера.
- Поиск по демонстрационному каталогу.
- Избранное и вкладки навигации.
- Демо-плеер интерфейса (пока без настоящего звука).

## Важно
Это прототип: каталог пока демонстрационный, настоящего потокового воспроизведения нет. Реальные музыкальные источники подключим через разрешённые API и с учётом условий провайдеров.

## Публикация
В корне репозитория находится `index.html`. Его можно бесплатно опубликовать через Cloudflare Pages, подключив GitHub-репозиторий `main` и выбрав корневую папку сайта. После публикации Cloudflare выдаст адрес вида `https://имя-проекта.pages.dev` и будет обновлять сайт при новых коммитах.

## Технологии
HTML, CSS и JavaScript без внешних зависимостей.
