# DIZZI

Мобильное музыкальное веб-приложение в духе Spotify: единый поиск, очередь воспроизведения, избранное и плеер в самом интерфейсе.

## Что работает

- Адаптивный тёмный интерфейс для мобильного браузера.
- Единый поиск по YouTube-видео/музыкальным записям и Audius.
- Поиск YouTube через публичные экземпляры Invidious API с несколькими резервными адресами.
- Воспроизведение YouTube внутри приложения через официальный YouTube IFrame Player API — без необходимости искать и вручную вставлять ссылку.
- Полноформатное потоковое воспроизведение доступных записей Audius.
- Мини-плеер, play/pause, предыдущий/следующий трек, перемотка и время воспроизведения.
- Избранное в локальном хранилище браузера.
- Публикация автоматически через GitHub Pages.

## Музыкальные источники

**YouTube:** DIZZI получает результаты поиска от публичных экземпляров Invidious, затем запускает выбранный ролик в официальном YouTube-плеере. Это позволяет искать известные песни прямо в DIZZI без Google Cloud API key и без скачивания/извлечения аудио. Не все ролики разрешают встраивание, а доступность публичных экземпляров API может меняться.

**Audius:** треки ищутся через публичный read-only API и потоково воспроизводятся напрямую, если запись доступна для стриминга.

Поиск использует открытые каталоги и не предоставляет собственного лицензионного каталога всех коммерческих песен. Регионы, правообладатели, ограничения встраивания и доступность источников могут повлиять на отдельные записи.

## Архитектурный референс

При разработке модели поиска и плеера изучен [OpenTune](https://github.com/harshitethic/OpenTune), открытый YouTube Music-плеер с Python/ytmusicapi backend и официальным встроенным YouTube-плеером. DIZZI опубликован как статический сайт на GitHub Pages, поэтому серверный backend из OpenTune нельзя запустить внутри Pages; текущая версия использует публичные Invidious API для получения поисковых результатов непосредственно из браузера.

## Публикация

Главная страница находится в `index.html`. Изменения ветки `main` автоматически публикуются GitHub Actions на GitHub Pages.

## Технологии

HTML, CSS и JavaScript, Web Audio/HTMLMediaElement для Audius, YouTube IFrame Player API для встроенного воспроизведения. Внешние npm-пакеты и платные сервисы не требуются.
