# DIZZI

Мобильное музыкальное discovery-приложение, работающее в браузере Android и других устройств.

## Что уже работает

- Адаптивный тёмный интерфейс.
- Поиск треков в каталоге Audius.
- Полноформатное потоковое воспроизведение доступных записей, а не только 30-секундных превью.
- Пауза/воспроизведение, отображение времени и перемотка.
- Избранное сохраняется в локальном хранилище браузера.
- Бесплатная публикация через GitHub Pages.

## Источник музыки и ограничения

DIZZI использует публичный read-only API Audius для каталога и потокового воспроизведения. Доступны только записи, которые есть в каталоге и разрешены к потоковому воспроизведению. Это не полный каталог всех коммерческих релизов; некоторые известные исполнители и песни могут не находиться.

Проект не загружает и не хранит музыкальные файлы. Полные записи воспроизводятся через источник, на котором они опубликованы.

## Разработка и публикация

Главная страница находится в `index.html`. Изменения в ветке `main` автоматически публикуются GitHub Actions на GitHub Pages.
